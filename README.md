# 📡 CEP Location System

Sistema web desenvolvido em **Streamlit** para consulta de CEP com retorno de informações geográficas e visualização em mapa.

---

## 🚀 Demonstração

O sistema permite que o usuário digite um CEP e receba:

- 📍 Cidade e estado
- 🏠 Rua / logradouro
- 🌐 Latitude e longitude
- 🧭 Visualização da localização em mapa

---

## 🧰 Tecnologias utilizadas

- Python
- Streamlit
- Pandas
- API de geolocalização (via função `buscar_cep`)
